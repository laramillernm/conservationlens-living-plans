# \# ConservationLens Living Plans

# 

# ConservationLens Living Plans is an open-source framework for keeping place-based conservation plans current.

# 

# It separates planning questions from datasets and analytical methods so updated information can be incorporated without rebuilding the plan from scratch.

# 

# \## Prototype v0.1

# 

# The first prototype will answer four questions:

# 

# 1\. What is exposed?

# 2\. What work has been completed?

# 3\. What important need remains?

# 4\. What has changed since the planning baseline?

# 

# \## Prototype Structure

# 

# \- `data/` - source and processed spatial data

# \- `config/` - project-specific settings

# \- `scripts/` - analysis and processing code

# \- `outputs/` - generated maps, tables, and reports

# \- `app/` - prototype application

# \- `docs/` - project documentation

# 

# \## Scope

# 

# Version 0.1 is intended to demonstrate the Living Plans concept, not create a complete planning platform.

# 

# The prototype will focus on one geography, a small set of indicators, and a repeatable update workflow.
